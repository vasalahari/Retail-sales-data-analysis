# Retail Sales Data Analysis

## 📌 Project Overview

This project focuses on analyzing retail sales data to identify sales trends, customer behavior, product performance, and key business insights using Python.

## 🎯 Objectives

- Analyze overall retail sales performance.
- Identify top-performing countries and products.
- Analyze monthly and yearly sales trends.
- Understand the relationship between quantity sold and revenue.
- Generate meaningful business insights through data visualization.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Data Analysis Process

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Data Visualization
6. Correlation Analysis
7. Business Insights

## 📈 Key Analysis

- Monthly revenue trend analysis
- Country-wise revenue analysis
- Top-selling products
- Quantity and revenue analysis
- Correlation analysis
- Sales trend visualization

## 🔍 Key Insights

- Sales showed fluctuations throughout the year with noticeable seasonal patterns.
- The analysis identified countries contributing significantly to overall revenue.
- Quantity sold has a strong positive relationship with revenue.
- Product and country-level analysis helped identify important sales contributors.
